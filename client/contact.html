Common questions

Do I need real money to use StockPie?

No. The prototype displays a sample portfolio and demonstration prices. No real money is used.

Is my password stored in plain text?

No. The server stores a salted scrypt hash in users.json, never the password itself.

Why does the form stop working when I open the file directly?

Because saving needs a server. Run node server/server.js and open http://localhost:3000.

Can I trade for real?

No. StockPie is not a broker and never executes real orders.
